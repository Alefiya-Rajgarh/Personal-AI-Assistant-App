# assistant_ai

Production-ready Flutter foundation for an AI executive assistant using a feature-first architecture, Riverpod, and GoRouter.

## Architecture

- `lib/core`: design system, routing, shared providers, utilities
- `lib/features`: feature-first folders with `data`, `domain`, and `presentation` layers

## Getting Started

1. Install Flutter $\ge 3.11$.
2. Fetch dependencies.
3. Run the app or tests.

This project is a starting point for a Flutter application.
